# 看山侦探事务所 V2.0 迭代说明

## 目标

在不扩张 CASE 001 主线和不接入真实 AI/OAuth 的前提下，增强用户主动性、知乎关联和证据一致性。

## 产品变更

### 1. 自行发起委托

- 首页新增“自行发起委托”入口。
- 参考创建案件交互，用户可输入 2-50 字问题，并配置案件类型、难度、预计用时和默认生成项。
- 页面保留“同步到知乎问题”开关，默认开启；开启时复制问题并打开知乎主站，由用户自行确认后续操作。
- 后端通过官方 `zhihu-cli search zhihu` 返回三条可回溯线索。
- 自定义委托是独立快查，不创建或覆盖 CASE 001 进度。
- AI 仅作为预检过程的界面表达，不生成事实结论。

### 2. 调查笔记同步知乎想法

- T04 默认开启“允许一键发布到想法”。
- 用户完成笔记时，将正文写入剪贴板并打开知乎想法页面。
- 不接 OAuth，不代表用户执行最终发布；发布动作由用户在知乎页面确认。
- 是否准备发布会随任务 payload 写入 SQLite，并显示在线索上下文中。

### 3. 证据上下文一致性

- E01 保留真实 CLI 结果的知乎原文链接。
- E02-E05 不再把泛搜索结果冒充“查看上下文”。
- 证据卡展开后直接还原任务当时选择的卷宗摘录、观点与理由、个人笔记或关键来源限制。
- 结案报告区分外部知乎原文与内部调查记录。

### 4. S 级与拼图规则

- S 级要求：五项调查全部完成、第一次推理成功、未使用协助结案。
- 结案时统一解锁 P8“印证”和 P9“真相”。
- 因此 S 级报告必然显示 5 份证据和 9/9 拼图。
- 跳过可选调查仍可正常结案，但最高为 A，且 P4/P5 保持缺失。

## 验收口径

- 1440x900 与 1366x768 无横向溢出。
- 自定义委托真实 CLI 成功时显示“知乎 CLI 实时线索”，降级时明确显示“演示线索”。
- 调查笔记发布开关默认开启，界面明确说明由用户最终确认发布。
- E03 展开内容必须与 T03 选择的观点和理由一致。
- 完成 T01-T05 并首次正确推理后，报告必须为 S、证据 5、拼图 9/9。
